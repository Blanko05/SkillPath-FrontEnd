# 📚 SkillPath Frontend (React)

This is the **frontend** for SkillPath, an AI-guided course recommendation platform, built with **React + Vite**.

## 🎯 Description

The app has three types of users:

- 🎓 **Students**:
  - Browse and search the course catalog
  - Take a short quiz and get AI-ranked course recommendations
  - Enroll/unenroll in courses and track their own enrollments
- 🧑‍🏫 **Managers**:
  - Create, edit, and delete their own courses
- 🛠️ **Admins**:
  - Reassign which manager owns a course
  - Manage users: edit details, change roles, delete accounts

Login and signup are included with a role-based flow (student/manager/admin). All data is persisted in the backend via PostgreSQL, and course recommendations are generated by OpenAI on the backend.

## 👨‍💻 User Requirements

1. **Sign up** with a name, email, and password - new accounts are always created as `student`; only an admin can promote someone to `manager` or `admin` afterward
2. **Log in** with email and password
3. **Students** can:
   - Take the quiz and view AI-generated recommendations
   - Enroll and unenroll in courses (with a confirmation step before unenrolling)
   - View their quiz history and their own enrollments
4. **Managers** can:
   - Create, edit, and delete courses they own
5. **Admins** can:
   - Reassign a course to a different manager
   - Edit, change the role of, or delete any user
6. The app remembers login sessions using `localStorage`
7. A light/dark theme toggle in the nav remembers the user's choice (also via `localStorage`) and otherwise follows the OS theme

## 🛠️ Technologies

- React 19 + Vite
- React Router 7
- React-Bootstrap / Bootstrap 5
- Axios
- **Third-party APIs called directly from the frontend** (not proxied through the backend):
  - Wikipedia REST API - a "Learn more about this topic" panel on each course's detail page
  - YouTube Data API v3 - related tutorial videos on each course's detail page (needs an API key, see below)
- `localStorage` for session and theme persistence

## 🚀 Getting Started

The backend must be running first (see its own README) - the frontend expects it at `http://localhost:5000`.

```bash
cd FrontEnd
npm install
npm run dev
```

The app runs at `http://localhost:5173`.

### Optional: enabling related videos

The "Related videos" panel on the course detail page needs a free YouTube Data API v3 key. Without one, that panel simply doesn't render - nothing else is affected.

1. Copy `.env.sample` to `.env`
2. Get a key from the [Google Cloud Console](https://console.cloud.google.com/) (enable "YouTube Data API v3", then create an API key under Credentials)
3. Set `VITE_YOUTUBE_API_KEY` in `.env`
4. Restart `npm run dev` (Vite only reads env vars at startup)
